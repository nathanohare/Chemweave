Added: Settings: a new Animations choice under Settings ▸ Preferences ▸ Interface (Off, Fast or Normal). The desktop app starts on Fast; the web version, and any computer set to reduce motion, starts on Off.
Added: Short, subtle animations throughout: dialogs, menus, tooltips, the Side Panel, toolboxes, ribbon tabs (the selected tab slides to the one clicked), mode changes, the File page, folding sections, status messages and slides being added or reordered. Nothing waits for them: everything is usable at once.
Added: Jumping to an item, such as a link in Help or a field the program points you to, now glides there when animations are on.
Changed: Check boxes have a clearer checked look (filled with the mode's accent color) and the check mark draws in.
Changed: Every existing animation now uses the same timings and follows the Animations setting, including the slide show's buttons, comment cards, the SI progress bar and highlights.
Under the hood: a test checks that every animation uses the shared timings and never animates a size or position; the motion rules are in the UI style guide (S91 to S97).
